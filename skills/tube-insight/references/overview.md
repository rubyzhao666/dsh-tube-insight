# Overview：视频概览（章节 + 金句）

> **何时读我**：用户问「这条视频讲了什么 / 概括一下 / 分章节 / 重点是什么 / 有没有金句 / 值不值得看」，或用户给了视频链接但没说清要哪种分析（默认模式）。也用于知识卡片、PRD 之前需要先建立全片结构时。
>
> **移植自**：TubeInsight `prompts/analysis.md`（Overview 提示词）。原版让另一个 LLM API 返回 JSON；这里改成**你自己按下面的 JSON 契约组织内容**，再渲染成用户要的形态。字段名、时间戳规则原样保留。

## 前置

1. 已经调过 `tube_transcript`，手上有时长 `durationSeconds`、`videoId`、标题、频道、章节列表（可能为空）。
2. 已用 `read` 读完 `transcriptPath` 全文。只看了预览就给概览是拆自己的台。

## 第一步：先按 JSON 契约组织内容

内部先把这个对象想清楚（字段必须齐全），再决定输出形态：

```json
{
  "chapters": [
    {"title": "章节标题", "timestamp": "0:00", "timestampSeconds": 0, "summary": "这一节讲了什么"}
  ],
  "keyQuotes": [
    {"quote": "清理后的原话", "timestamp": "2:30", "timestampSeconds": 150}
  ],
  "keyMoments": [0, 150, 300]
}
```

- 用户明确要 JSON（比如要喂给别的程序）时，只输出合法 JSON，不加 Markdown 围栏、不加解释。
- 默认输出下面的 Markdown 版本；JSON 只是中间结构，不用展示。

## 第二步：章节规则

- 工具返回的 `chapters`（从视频描述里解析出来的章节，字段 `{title, startSeconds}`）可以作为骨架参考；但它可能为空或不完整，**覆盖全片的硬规则仍以转录为准**，缺的部分要自己补。
- **覆盖全片**：章节从 [0:00] 开始，一路要覆盖到视频结束，不能停在半路。最后一章的起点必须晚于全片 75%（`durationSeconds × 0.75`）——比如 60 分钟的视频，最后一章必须在 45 分钟之后开始。
- 章节数量由内容决定：30 分钟的视频可能 6–10 章，3 分钟的视频 2–3 章就够。不要为了凑数把同一段拆开，也不要为了省事把一整段话题合并。
- 章节标题要**信息性**：写「为什么 RAG 在长文档上失效」而不是「第二部分 / 中间部分 / 继续」。
- `summary` 用 1–2 句说清这一节的实际内容，不要复述标题。

## 第三步：金句规则

选 3–5 条，优先挑：

- 反直觉、挑战常识的判断；
- 让人「原来如此」的事实或数据；
- 能把一个观点讲活的具体故事或类比；
- 能一句话概括整段论证的漂亮表达。

**时间戳必须来自转录行首真实存在的 `[MM:SS]`**，找包含这句话的那一行，用它行首的时间戳。换算秒数：`[2:30] = 150`。不允许出现：

- 编造转录里没有的时间戳；
- 用 `0:00` 当默认值（除非内容确实在第 0 秒）；
- 超出 `durationSeconds` 的时间。

**清理原话**（保留发言人的用词和语气，只做可读性打磨）：

- 用标题和转录 md 里的「## 视频描述」校正人名、公司名、专有名词、术语拼写；
- 补标点、修断句；
- 去掉 `um`、`uh`、`like`、`you know`、`sort of`、`kind of` 这类口头填充词；
- 去掉口吃、重复词、错误的开头；
- 不要改写成书面腔，不要缩写观点、不要加发言人没说的内容。

## 第四步：关键瞬间

`keyMoments` 给 3–7 个秒数（升序），是「最值得跳回去看」的位置：金句出处、关键演示、结论落点。用户要时间轴或高亮时用得上。

## Markdown 输出模板

```markdown
# {视频标题}
**频道**：{频道} ｜ **时长**：{mm:ss} ｜ **字幕**：{语言}（原生 / 自动生成）

## 一句话总结
> 一句话说清全片的核心主张或价值（不要写「本视频介绍了……」这种废话）。

## 章节
- [0:00](https://youtu.be/<videoId>?t=0) **{标题}** — {这一节讲了什么}
- [3:12](https://youtu.be/<videoId>?t=192) **{标题}** — {…}
- ……（覆盖到结尾，最后一章 > 75% 处）

## 金句
1. > {清理后的原话}
   — [12:40](https://youtu.be/<videoId>?t=760)
2. ……

## 关键时刻
- [2:30](https://youtu.be/<videoId>?t=150)：{这里发生了什么}
- ……

## 值不值得看
{1–3 句判断：适合谁、信息密度如何、是否有过时内容。明确标注这是你的判断。}
```

## 交付前自查

- 章节是否从 0 覆盖到片尾？最后一章起点是否 > 75%？
- 每条金句的时间戳是否能在转录里逐字找到？
- 双引用里的秒数和方括号时间是否一致？
- 金句是否清理了口头语、但没有改变原意？
- 没读全文就下结论了吗？是的话回去读。
