# Notes：时间戳笔记润色

> **何时读我**：用户说「把这句话记下来」「这个时间点说了什么，整理成一句笔记」「帮我顺一下这句原话」「保存这个金句」，或给了一个 `[MM:SS]` / 一段听写不清的话要你整理成自洽的笔记。也用于把零散笔记整理成清单。
>
> **移植自**：TubeInsight `prompts/note-cleanup.md`（保存笔记时的清洗提示词）。原版由扩展定位用户点选的那一行再交给 LLM 润色；这里改成**你自己在转录里定位并润色**。九条清洗规则与 JSON 输出形状原样保留。

## 前置：先定位

用户可能给三种输入：

- **给了时间戳**（`[12:30]` 或 `12:30`）：在 `transcriptPath` 里用 `grep` 搜该时间戳前缀（注意 `[12:3` 这类模式），再 `read` 前后几十行。
- **给了一句原话**：`grep` 搜这句话的关键词片段，定位到行号后 `read` 邻近内容。
- **没给具体位置**：先问一句是哪个时间点/哪句话，不要瞎猜；如果用户描述的是主题，用 `grep` 找最相关段落并让用户确认。

定位后取这些上下文：

| 片段 | 范围 |
|---|---|
| BEFORE | TARGET 行前 2 行 |
| TARGET | 用户所指的那一行 |
| AFTER | TARGET 行后 4 行 |
| FULL CONTEXT | TARGET 前 8 行到后 12 行（补齐句子边界用） |

## 清洗规则（逐条执行）

1. 找出包含 TARGET 时刻的**完整句子或完整想法**。
2. TARGET 行说到一半就断：用 FULL CONTEXT 往后补到下一个完整句子结束。
3. BEFORE 行从半句开始：用 FULL CONTEXT 往前找到这一句的开头。
4. 去掉口头填充词和噪音：`um`、`uh`、`like`、`you know`、`sort of`、`kind of`、口吃重复、错误开头。
5. 修语法、拼写、标点，让笔记读起来是正确、通顺的句子。
6. 首字母大写，结尾有完整句末标点（句号、问号等）。
7. 用视频标题和转录 md 里的「## 视频描述」校正人名、公司名、专有名词。
8. **保留发言人真实的意思和措辞**：只做可读性打磨，不总结、不压缩观点、不添加他没说过的内容。
9. 目标长度 1–3 个完整句子；最终笔记必须是读完就结束的完整表达，不能留半句尾巴。

补充：

- 视频是中文时输出中文，英文时输出英文润色版；用户要双语时按 `references/translation.md` 加一行译文。
- ASR 转录的同音错字按上下文修正，拿不准的保留并标「（疑似 ASR 错误）」。

## 输出

默认形态（对话里直接给）：

```markdown
> {清理后的完整句子。}
— [12:30](https://youtu.be/<videoId>?t=750)
```

用户要机读时只输出合法 JSON：

```json
{"quote": "清理后的完整句子"}
```

## 多条笔记整理

用户一次给多条笔记（时间戳列表、散句、或已保存的笔记清单）时：

1. 逐条定位、清洗，保持用户给的顺序；
2. 输出表格：

```markdown
| 时间 | 笔记 | 出处 |
|---|---|---|
| 2:14 | {清理后的笔记} | [2:14](https://youtu.be/<videoId>?t=134) |
| 12:30 | {清理后的笔记} | [12:30](https://youtu.be/<videoId>?t=750) |
```

3. 同一观点被记了多次时合并，并在表里保留最早的时间戳。

## 沉淀

用户要把笔记连同视频一起保存时：

- 存成知识卡片 → 按 `references/knowledge.md`，笔记放进「✍️ 我的笔记」，此时不要再给 `tube_export` 传 `notes`（会重复）；
- 直接导出 → 调 `tube_export`，`module=knowledge`（或用户指定模式），`notes` 传**字符串数组**：每条用户原始笔记一项（原样，不要传你润色后的版本；用户明确要求保存润色结果时才传润色版并说明），工具会追加成「## 我的笔记」。

## 交付前自查

- 笔记是完整句子吗？有没有开头半句或结尾断在半截？
- 去掉了口头填充词，但观点和措辞还是发言人的吗？有没有被我总结或加料？
- 时间戳是转录里真实存在的行首时间吗？链接秒数换算对吗？
- 人名/专名是否用标题校正过？
- 多条笔记的顺序和用户给的一致吗？
