# Translation：翻译与双语

> **何时读我**：用户要「把字幕翻译成中文 / 英文」「双语对照」「把这条视频的内容翻成 X 语言」，或要求任一模式（概览、情报、洞察、PRD、对比、卡片）用英文/双语产出。
>
> **移植自**：TubeInsight `prompts/translation.md`（原版用于字幕分段翻译与界面内容翻译）。原版把 1–4 个语义段发给 DeepSeek 返回 JSON；这里改成**你自己按同样的规则翻译**，分段协议与 JSON 形状保留，用于机读或大批量翻译。

## 语言模式

先确认用户要哪种，默认「中文」：

| 模式 | 产出 |
|---|---|
| 原文（Original） | 不翻译，只做可读性整理（补标点、去口头语、修专名） |
| 中文 | 默认。正文和分析结论用中文，专有名词/技术词保留原文 |
| 双语 | 逐段对照：原文在上、译文在下，时间戳只出现一次 |
| 其他语言 | 用户指定语言时按同一套规则做（语气一致、自然句式、保留专名） |

## 通用翻译规则（严格遵循）

- 语气和文体与原文一致：口语保持口语，正式保持正式。
- 用自然的目标语言句式，**不要逐词直译英文语序**。
- 不翻译：专有名词、品牌名、通常保留英文的技术词（API、AI、GitHub、Claude Code、skill 等）、时间戳。
- 保留全部格式：分段、列表、Markdown 结构、引用块、时间戳。
- 先理解完整意思再落笔，不要因为源字幕在某个位置断句就翻出半句话。

## 中文细则

- 用现代口语化简体中文；原文不正式就不要写成僵硬书面语。
- 用自然中文语序，不要镜像英文句法。
- 人称用「你」，不用「您」，除非原文明确使用敬语。
- 面向懂技术的产品/科技读者；AI、API、GitHub、Claude Code、Codex、skill、builder、deck、Chrome 这类词按自然用法保留英文。
- 中文与相邻英文/数字之间留空格，例如 `使用 Claude Code`、`过去 6 个月`。
- 去掉无意义的口头填充词，但保留真实的犹豫或强调。

## 字幕 / 转录翻译流程

1. `read` 转录全文（`transcriptPath`）。长视频按 `offset` / `limit` 分段读，按批翻译。
2. **每批 20–40 段**，保持原文 `[MM:SS]` 行首不变，不合并、不拆分、不遗漏、不重排段落。
3. 先扫一遍做**术语表**：出现的人名、产品名、公司名、缩写、技术词列成一页，全文统一译法；用标题和转录 md 里的「## 视频描述」核准拼写。
4. 翻译时把被断开的句子按语义补齐；但输出仍按原来段落的边界落回，不能因为「句子更完整」就把两段合成一段。
5. 大批量翻译时，每完成一批在回复里标「第 x/y 批」，用户可以随时叫停。
6. 如果用户只要部分内容（某一章、某个主题相关段落），先问清范围，不要默认翻全片。

### 机读输出（用户明确要 JSON 时）

```json
{"segments": [{"id": "原段 id 或时间戳", "text": "译文"}]}
```

- `id` 原样复制输入，只翻译 `text`；
- 只输出合法 JSON，不要围栏、说明、额外字段。

### 双语输出格式

```markdown
[2:14] The model only works if you feed it the right context.
        模型只有喂进正确的上下文才有效。

[2:38] That is why retrieval matters more than prompt tricks.
        所以检索比提示词技巧更重要。
```

时间戳只写一次，紧贴原文行；用户要的是「看双语字幕」还是「做学习笔记」决定要不要保留原文。

## 界面内容 / 已有产出翻译

翻译概览、情报、洞察、PRD、知识卡片等已有内容时：

- 保留含义与语气；章节标题、摘要、金句、笔记都要译，但不要添加原文没有的解释、标签或事实。
- 不合并、不拆分、不遗漏、不重排段落；时间戳与链接原样保留，只改文字。
- 金句译文要贴原话，不要为了通顺改掉发言人的立场或措辞。
- 双引用格式不变：`[2:14](https://youtu.be/<videoId>?t=134)` 中的时间与秒数不要因为翻译而变。

## 存档

用户要保存时调 `tube_export`：`module=translation`，`videos=[视频来源]`，`markdown=译文/双语稿正文`。

## 交付前自查

- 语气是否与原文一致？是不是英文语序直译？
- 专有名词、技术词、时间戳有没有被误翻？
- 段落数、顺序、时间戳是否与原文一一对应，没有偷偷合并或删段？
- 中文里中英文之间是否有可读空格？有没有用「您」？
- 双语模式的时间戳是否只出现一次、和链接秒数一致？
- 用户要的范围是否被放大（只让翻一章却翻了全片）或缩小？
